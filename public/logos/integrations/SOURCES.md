Page-header logos were copied from the page exactly; the only addition is the `xmlns` attribute a standalone SVG file needs. The two drawn inline (Syrve, Zonal) were saved from the page with the colours the page's stylesheet gives them written onto each shape, since a standalone file cannot read that stylesheet; the shapes are unchanged.
